# imports

Added by `/mindtix import <path>`: each export becomes one folder of plain text here.
This folder is **not committed** (see `.gitignore`), because exports hold other people's
messages and personal data. The notes built from them are.

Data exports (Instagram, chats, Google Takeout), transcripts, articles, PDFs. The AI extracts
what they say about you into `self/`, `projects/` and `hobbies/`, and leaves out any
secrets or ID numbers.
