# Map: statistics for an A/B test (example)

**Goal:** analyse a real A/B test at work and explain the result to my team, by 2026-12-01.
**Level at start:** knows averages; shaky on spread; no probability. (From the interview.)
**Tested by:** presenting one real experiment.

## Modules
- [x] Averages: mean, median, when they differ
- [ ] Spread: variance, standard deviation (needs: averages)
- [ ] Probability basics (needs: nothing)
- [ ] Distributions: normal, binomial (needs: spread, probability)
- [ ] Sampling and standard error (needs: distributions)
- [ ] A/B test: hypothesis, p-value, confidence interval (needs: all of the above)

## Where people get stuck
- Reading a p-value as "the chance the result is true"
- Mixing up standard deviation and standard error
