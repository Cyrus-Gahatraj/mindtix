# learning

What you're learning right now. One folder per topic, holding `map.md` (goal, level, modules,
sticking points) and `sessions.md` (what you produced and how it went). `mistakes.md`
collects errors across topics so repeated ones can be traced to a root cause. See
`_example/`. `reviews.csv` is written by the scripts: one row per card made or graded, the
evidence for `self/insight/learning.md`.
